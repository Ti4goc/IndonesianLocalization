# Indonesian Localization Mod for Cities: Skylines II

An Indonesian (id-ID) translation for Cities: Skylines II, adapted with clear terminology commonly used by Indonesian players.

## Translation Progress

This is the first public release. It currently contains **13,476 localized game text entries**, covering core interface text, tutorials, statistics, gameplay messages, and a growing selection of important assets. The translation is still in progress. DLC region packs, content packs, and less visible asset variants are not yet fully translated, but support for them is planned for upcoming updates.

## A Note from the Creator

I am not a native Indonesian speaker, and I do not speak Indonesian myself. This mod comes from a wish to see Cities: Skylines II translated for as many players as possible, in as many languages as possible. Translations are contributed and reviewed by the community on Crowdin for free. You can also contact me directly on Discord at **Ti4goc#0001**.

## Requirements

You must install **I18NEverywhere**, which enables this mod to translate other mods alongside the base game.

## Features

* Indonesian translation without changing the game's visuals or gameplay
* Mods translated automatically via I18NEverywhere
* Consistent terminology throughout, from the base game to mods
* Frequent translation updates

## Compatibility Warning

Do not enable this mod together with another custom language localization mod, for example a Portuguese, Dutch, Hungarian, Thai, Turkish, or other non-built-in language locale mod, at the same time, unless that mod's SystemLanguage tag is guaranteed distinct from this one. Two custom locale mods sharing the same internal language tag can crash the game on startup.

## DLC Support

DLC region packs and content packs, including Leisure Venues, Mediterranean Heritage, Urban Promenades, Bridges and Ports, and more, are not yet fully translated, but support is planned for future updates.
